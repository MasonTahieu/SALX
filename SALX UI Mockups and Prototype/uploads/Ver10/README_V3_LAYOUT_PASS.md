# SALX Frontend V3 — Logo + Layout Harmony Pass

Baseline: `SALX_FRONTEND_v3.zip`

This pass keeps the existing React/Vite structure and design language, while:
- integrating the supplied SALX logo into the shared header;
- using the SALX mark inside the retirement certificate stamp;
- tightening the desktop composition and content width;
- reducing excessive vertical spacing in Home/Market/Leaderboard/Retire;
- making the Home hero image ratio closer to the supplied reference;
- removing the extra pressing marquee;
- keeping the Market footer route-specific instead of showing it on every route;
- refining button, card, filter, table, and certificate proportions;
- preserving responsive behavior and reduced-motion support.

Logo assets added:
- `public/assets/salx-logo-source.png` — original uploaded source
- `public/assets/salx-wordmark-dark.png` — transparent dark-background wordmark
- `public/assets/salx-mark-dark.png` — transparent dark-background icon mark

Business/service/contract logic from the supplied frontend baseline was not introduced or replaced in this visual pass.
